# Keyhalt, storyboard, 60 seconds

Voice: engineer actually running an agent fleet on NEAR, measured, not salesy.
No music. Each beat gets one large on screen sentence.

Beat 1 (0 to 6s), the hook
- Image: fleet list with all three agents active
- Voice: "Every agent fleet starts with keys. The operators call them, the parent does not, and nobody is watching."
- On screen: "Their keys work. Nobody is watching."

Beat 2 (6 to 13s), the map of keys
- Image: agent-1b detail page, operator keys with tags
- Voice: "Per agent, the admin owns the receiver and method ACLs. Operator keys are tagged."
- On screen: "ops-a, ops-b, admin, recovery. All scoped."

Beat 3 (13 to 22s), the freeze
- Image: frozen agent detail page
- Voice: "If the agent does something I do not want, one admin transaction freezes it."
- On screen: "keyhalt freeze agent-1b · one tx"

Beat 4 (22 to 30s), the refusal receipt
- Image: timeline refused row
- Voice: "The next call is refused. Controller is frozen. The refusal is on chain, as a receipt, with the tx hash."
- On screen: "Refused · controller is frozen"

Beat 5 (30 to 38s), the audit chain
- Image: audit entries
- Voice: "Every grant, every revoke, every freeze is an entry in a SHA-256 chain. The chain can be verified offline."
- On screen: "Every event hashes the previous."

Beat 6 (38 to 48s), why
- Image: CLAIMS.md first rows
- Voice: "84 Rust tests, 41 TypeScript tests, 7/7 near-workspaces tests. All forty claims map to one of those."
- On screen: "Every claim maps to a passing run."

Beat 7 (48 to 60s), close
- On screen: "github.com/unifyWeb3/keyhalt · MIT · testnet"
- Voice: "Testnet only, MIT licensed. https://github.com/unifyWeb3/keyhalt."
